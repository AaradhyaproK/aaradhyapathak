## Introduction

Technical recruitment processes frequently encounter severe bottlenecks during initial candidate screening. In traditional recruitment workflows, senior engineering leads dedicate over 40 hours each week conducting repetitive preliminary interviews.

To solve this challenge, I architected **InterviewXpert (AI Base)**, an automated candidate evaluation platform that leverages **Google Gemini** multimodal models and **AssemblyAI** real-time speech transcription to deliver objective, scalable candidate screening.

## The Architectural Challenge

Designing an automated assessment platform requires solving three distinct engineering problems:

1. **Sub-second Speech Processing**: Transcribing candidate audio responses with high linguistic accuracy and minimal latency.
2. **Context-Aware Prompt Structuring**: Ensuring the generative AI model scores responses against standardized technical rubrics without conversational drift.
3. **High-Concurrency Scalability**: Supporting dozens of concurrent candidates without exhausting API rate limits or degrading audio fidelity.

```typescript
// Sample API client integration pipeline
import { AssemblyAI } from "assemblyai";
import { GoogleGenerativeAI } from "@google/generative-ai";

const speechClient = new AssemblyAI({ apiKey: process.env.ASSEMBLYAI_KEY! });
const genAI = new GoogleGenerativeAI(process.env.GEMINI_API_KEY!);

export async function processInterviewResponse(audioUrl: string, rubricPrompt: string) {
  // 1. Transcribe audio response
  const transcript = await speechClient.transcripts.transcribe({ audio: audioUrl });
  
  // 2. Evaluate with Gemini Pro model
  const model = genAI.getGenerativeModel({ model: "gemini-1.5-pro" });
  const result = await model.generateContent([
    rubricPrompt,
    `Candidate Transcript: ${transcript.text}`
  ]);
  
  return result.response.text();
}
```
